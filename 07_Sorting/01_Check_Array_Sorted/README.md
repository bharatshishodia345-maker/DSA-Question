# Check Array Sorted

## Problem
Check whether an array is sorted in ascending order.

## Approach
- Traverse the array.
- Compare each element with the next element.
- If the current element is greater than the next element, return `False`.
- Otherwise return `True`.

## Time Complexity
O(n)

## Space Complexity
O(1)

## Example

Input

```python
[1,2,3,4,5]
```

Output

```
True
```
