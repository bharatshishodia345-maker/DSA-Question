# Sleep Sort

## Problem

Demonstrate the Sleep Sort concept using Python's `time.sleep()` function.

## Approach

- Iterate through each element.
- Sleep for the value of the element.
- Print the element after the delay.

> Note: This implementation is only for understanding the concept. It is **not** the actual multithreaded Sleep Sort algorithm.

## Time Complexity

Depends on the values inside the array.

## Space Complexity

O(1)

## Example

Input

```python
[3,5,2,1]
```

Output

```
3
5
2
1
```
