## 04. Bubble Sort

### 📌 Problem

Sort an unsorted array in ascending order using the Bubble Sort algorithm.

### 💡 Approach

Bubble Sort repeatedly compares adjacent elements.

If the left element is greater than the right element, both elements are swapped.

After every pass, the largest unsorted element moves to its correct position at the end of the array.

Input:

```text
