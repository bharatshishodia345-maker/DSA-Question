# Bubble Sort

## Problem

Sort an array in ascending order using the Bubble Sort algorithm.

## Approach

- Compare adjacent elements.
- Swap them if they are in the wrong order.
- After each pass, the largest element moves to its correct position.
- Repeat until the array is completely sorted.

## Time Complexity

- Best: O(n²)
- Average: O(n²)
- Worst: O(n²)

## Space Complexity

O(1)

## Example

Input

```python
[2,5,6,1,4,3]
```

Output

```python
[1,2,3,4,5,6]
```
