# Reverse String Using Stack

## Problem

Reverse a given string using the Stack data structure.

## Approach

A Stack follows the **LIFO (Last In, First Out)** principle.

1. Push every character of the string into the stack.
2. Pop characters one by one.
3. Append each popped character to the result.
4. The resulting string is the reverse of the original string.

olleH

OUTPUT:-
